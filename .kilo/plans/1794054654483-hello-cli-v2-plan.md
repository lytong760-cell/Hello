# Hello CLI — v2 Plan (Detailed)

## Goal
Extend Hello CLI (Zig) with streaming responses, full tool-calling for all providers, reliability, agent modes, MCP (stdio), and in-process subagents.

## Key Decisions (resolved)
- Streaming API: provider accepts a callback `fn (*anyopaque, []const u8) void` for token chunks; REPL passes a stdout writer callback. Tool calls are accumulated and returned after stream completes.
- SSE failure: abort the turn with an error (no non-streaming fallback).
- Plan mode: write/edit/bash tools are exposed but gated behind a stronger confirmation prompt (not hidden).
- MCP: stdio transport only.
- Subagents: in-process isolated agent loop with recursion guard (max depth 1).
- Context compaction: hybrid — drop oldest if over 2x budget; otherwise summarize via LLM.

## Architecture Changes

### llm/provider.zig
New signature:
```
pub const StreamCallback = *const fn (ctx: *anyopaque, chunk: []const u8) void;
pub fn chatStream(
    allocator, cfg, messages, tools_json,
    on_token: ?StreamCallback, on_token_ctx: *anyopaque,
) !Response
```
`chat` becomes a thin wrapper that collects into an ArrayList and returns full text (for one-shot/tests).

Provider implementations:
- OpenAI/Kilo: POST with `stream: true`. Read response body incrementally via `req.reader()`. Parse SSE lines: `data: {...}`. Accumulate `choices[0].delta.content` (emit via callback), and `delta.tool_calls[]` (by index) into a `std.ArrayList(ToolCallAccum)`. On `[DONE]`, finalize.
- Anthropic: POST `/v1/messages` with `stream: true`. Parse events: `content_block_start`, `content_block_delta` (text_delta / input_json_delta), `content_block_stop`, `message_stop`. Accumulate tool_use blocks.
- Google: POST `streamGenerateContent?alt=sse`. Parse `candidates[0].content.parts[0].text` deltas.

Tool-calling for Anthropic: send `tools` array (`{name, description, input_schema}`) and parse `tool_use` content blocks. For Google: send `tools.functionDeclarations` and parse `functionCall`.

Retry/backoff: wrap each HTTP attempt in a loop (3 tries, delays 250ms/1s/4s) on connection errors or 5xx. Do not retry on 4xx.

### tools/registry.zig
- Add `mode` field filter: `runTool` unchanged, but `availableTools(mode)` returns subset.
- Plan mode: all tools available but `isDangerous` returns true for write/edit/bash (stronger confirm).
- Add MCP tool routing: if tool name starts with `mcp__`, route to MCP client.

### Agent modes
- Config: `mode: []const u8` (default "code").
- `--mode` flag and `/mode <name>`.
- System prompt prefix per mode:
  - code: current.
  - plan: "You are in planning mode. Prefer reading/searching; writes require confirmation."
  - debug: "Focus on diagnosing; use bash to reproduce."

### MCP client (new src/mcp.zig)
- Struct `McpServer { name, command, args, env, process, ... }`.
- On startup, for each configured server: spawn process, send `initialize` JSON-RPC over stdin, read response, send `tools/list`, register tools as `mcp__<server>__<tool>`.
- `callTool(server, tool, args_json) -> []u8`: send `tools/call`, read response, extract text content.
- On crash/EOF: mark server dead, skip its tools.

### Subagents (new src/subagent.zig)
- `runSubagent(allocator, cfg, cwd, task, depth) -> []u8` summary.
- Creates isolated messages, runs agent loop with max 10 turns, returns final assistant text.
- Recursion guard: if depth >= 1, return "max depth reached".
- Slash command `/task <description>`.

### Context compaction (in repl.zig)
- Estimate tokens = sum of message lengths / 4.
- Budget = 80000 tokens (configurable).
- If estimated > budget * 2: drop oldest non-system messages until under budget.
- Else if estimated > budget: take oldest half of non-system messages, call LLM to summarize into one system note, replace them.

### Memory cleanup
- Use an arena allocator per turn in REPL and subagent; reset after each turn.
- Keep config/skills on page allocator (long-lived).

## Failure Modes
- SSE parse error: abort turn, print error, keep session unsaved for that turn? Save previous state.
- MCP server fails to start: log and skip.
- Subagent error: return error text to parent as tool result.
- Compaction LLM failure: fall back to dropping oldest.
